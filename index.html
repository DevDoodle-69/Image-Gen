Image Generation API

Generate AI images with customizable models and aspect ratios

API Endpoint

GET /image?prompt=<prompt>&model=<1-4>&ratio=<1-6>

Parameters

Parameter Description Values
prompt Image description String
model AI model selection 1: flux-schnell
2: imagen-3-fast
3: imagen-3
4: recraft-v3
ratio Aspect ratio 1: 1:1
2: 16:9
3: 9:16
4: 3:2
5: 4:3
6: 5:4
